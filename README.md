# Mon écosystème numérique de thèse

## Auteur
Jallal Amiri — Université Abdelmalek Essaâdi.

## Objectif
Organiser les ressources de recherche liées à la classification
d’images médicales et à l’optimisation des hyperparamètres.

## Périmètre
- Classification pulmonaire et cérébrale.
- Réseaux convolutifs, notamment DenseNet121.
- Stratégies BO → MRFO et BO → IBWO → MRFO.

## État du projet
Le dépôt documente progressivement les données, les références,
les configurations et les règles d’utilisation de l’IA.
Il ne constitue pas encore une reproduction complète des expériences.

## Données
Les images médicales ne sont pas incluses dans ce dépôt.
Leurs sources, versions et restrictions seront documentées.

## Livrables
- Plan de gestion des données.
- Bibliographie et journal de contrôle.
- Charte personnelle d’utilisation de l’IA.
- Documentation des expériences.

## Reproduction
Les commandes seront ajoutées après vérification de leur exécution.
