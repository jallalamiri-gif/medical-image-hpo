# Plan de gestion des données

## 1. Nature des ressources
Images médicales réutilisées, configurations, partitions,
journaux d’optimisation, prédictions et métriques.

## 2. Documentation
Chaque expérience devra être reliée à un identifiant,
un jeu de données, une version, un split et une configuration.

## 3. Qualité
Vérifier les fichiers illisibles, les étiquettes et les doublons.
Documenter les limites concernant les identifiants patients.
Séparer les données avant augmentation ou suréchantillonnage.

## 4. Sauvegarde
Mettre en œuvre une stratégie 3-2-1.
Les supports, la fréquence et les tests de restauration
restent à renseigner selon les moyens effectivement utilisés.

## 5. Confidentialité
Ne pas diffuser de données personnelles, de secrets
ou de ressources dont les droits ne permettent pas le partage.

## 6. Archivage
Conserver les configurations, partitions autorisées,
journaux et prédictions nécessaires à la vérification.
La durée de conservation sera définie avec l’encadrement.

## Statut
Version initiale à compléter avec l’inventaire réel.
